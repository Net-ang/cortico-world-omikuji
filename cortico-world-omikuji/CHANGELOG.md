# Changelog

## 0.3.2

pet 模式下**解签也归桌宠写**——整张牌的话都是它的。

- `omikuji_record({ text, reading?, date? })` 新增 `reading`（解签）：两三句、40–120 字，说清这一天该怎么过。`text` 仍是签文（两句 14–18 字）。只给 `text` 也能记，`reading` 缺席就不显示。
- brief 里分开写清两种写法的要求，并把星级、宜忌、幸运四项当「既成事实」交给它——这些数字它不能改。
- 存储升级：`omikuji-wording-*.json` 的一条记录变成 `{ text, reading?, createdAt }`，老记录（只有 `text`）照样能读。
- 面板：pet 模式写过的牌面显示「签文 + 它写的解签」；`PanelSnapshot` 多一个 `writtenReading`。
- 元数据：署名 `author.name = 奶糖_net`（npm 账号仍是 `net_ang`），补上 `repository` / `homepage` / `bugs` 指向 GitHub 仓库，LICENSE 版权人改成本人。
- 测试 43 项、面板冒烟 32 项全过。

## 0.3.0

解签加厚，签面从「一句话」变成一张卡。

- **详批**：每档 3 段、每天轮换，比解语长一段，说清这一签落在哪件事上。
- **六项运势**：恋爱运、事业运、财运、健康运、社交运、摸鱼运，各 1–5 颗星。星级由档位定基线（上上签 5★、大凶 1★），每项再浮动一颗，所以同档不同天也不一样。回执里用 `★★★☆☆` 画，面板里是两列星条。
- **幸运物 / 幸运数字 / 幸运方位**：连同原有的幸运色，凑成四项。
- **节气与月相**：签面加一行时令（如「小雪 · 雪还没积起来，先试试　月相·望月 · 最亮的一夜，适合被看见　还有 13 天到大雪」）。节气取常年日期表、月相按朔望月平均长度推算，都是**近似**，个别年份节气会差一天。
- pet 模式把星级、宜忌、幸运四项当「事实」一并交给桌宠，句子仍由它写。
- 测试 42 项、面板冒烟 31 项全过；`copy-audit` 与 `preview` 跟着更新。

## 0.2.0

- **面板有了自己的语气**：顶部一段引言（「在桌宠与世界交汇的日常里……」），牌底一句收束（「愿你今天顺手抽到的那一签，刚好对上此刻的心情。」）。免责句仍在最下面。
- **封着的状态更明确**：抽签前是虚线牌 + 一枚淡「封」字印，翻开后「封」印消失、收束句出现。
- **抽签动画钩子**：卡片只在「刚抽出来」那一次渲染带 `om-reveal`，其余状态不带；关键帧留在 `dist/webui.css` 末尾，改样式即可，不用动 js。
- **抽签动画**：点「抽今天的签」先播 `assets/draw.mp4`（720×720 / 5.06 秒 / 静音），播完再揭晓；拿不到素材或播不完都直接揭晓。素材经面板方法 `video` 用 `$file` 流式送出。包体因此从 49 kB 涨到约 1.1 MB。
- 离线预览：`make-panel-preview.mjs` 生成 `panel-preview.html`（内联了视频），双击就能反复按「抽今天的签」调动画，不用装进 Coopanion。

- **换成每日真随机盐**：只有**真抽签**（工具 `omikuji_draw`、面板「抽今天的签」按钮）才会用 `crypto.randomBytes` 摇一个 64 位盐并落盘 `omikuji-days.json`。同一天同一台机器仍只有一张签，但明天是另一张、两台机器各摇各的——不再是「日期加一个装好就不变的盐」那样固定。
- **读不产生随机**：系统前缀那一行、打开面板、七天回看都只读（面板方法拆成 `snapshot` / `draw`）。**没抽过的日子，事后回看就是「日期 + 固定盐」**，跟 0.1.3 算出来的一致。
- **只留七天**：每次落盘自动删掉七天前的条目，面板那七天横排正好是这份数据的窗口。
- **七天以外回落**：那些日期没有当日盐了，改用固定的本机盐（`omikuji-salt.json`）去算，仍然确定、跨机器一致。`worlds.omikuji.salt` 现在只管这条回落路径。
- 新增 `src/daysalt.ts`；签到算法与取数顺序没动（种子串仍是 `omikuji/v1|<盐>|<日期>`）。
- 测试 41 项：新增 11 项覆盖「读不摇盐 / 抽才摇盐」、当日盐复用、跨机器不同、重启后从盘上读回、补抽过去的日子不摇盐、七天裁剪、回落确定性、清空重建。

## 0.1.0

首个公开发布。

**签**

- 种子 = `SplitMix64(FNV-1a("omikuji/v1|本机盐|YYYY-MM-DD"))`；引擎自带，取数用拒绝采样，不读时间、不碰 `Math.random`。
- 八档（上上签、大吉、中吉、小吉、平、末吉、小凶、大凶）完整覆盖 0–100，加载签库时校验不许有缝。
- 内置签库：每档 5 句签文、3 句解语，宜与忌各 24 条，幸运色 16 种，意象池 24 个。
- 本机盐首次使用时生成并落盘，同一天在同一台机器上恒定，换机器则不同；`worlds.omikuji.salt` 可覆盖，用于在别的机器上复现同一批签。

**工具**

- `omikuji_draw({ date? })`：取某一天的签，不传日期即今天；日期必须真实存在，`2026-02-30` 直接报错。同一天重复调用返回同一份内容。
- 回执的分数只写「N 分」，不写分母。
- 每张签末尾都带一句「相信科学，仅供娱乐参考。」，面板牌面同样带。
- 环境段每轮两行：今天的签号档位与分数，以及措辞归谁写。常用问法（「今日气运」「测测今天」这类）写进了提示词：取一次签、用自己的话答，不贴回执原文；凶档只是纸面玩笑，不许吓人。
- 挂载时推 `omikuji.started`。

**措辞**

- `worlds.omikuji.wording`：`builtin`（默认，签库成句）或 `pet`（桌宠自己写）；下拉选择，热改即生效。
- pet 模式下 `omikuji_draw` 只回事实与写作约束，不成句；新增 `omikuji_record` 把写好的正文落盘，同一天只认第一份，之后原样返回。
- 分寸只定约束不定口吻：每档一句写作界限，两句、14–18 字、不作断言；语气底线写明「只当玩笑话，凶档也不许吓人」，并要求把免责句一起说出来。

**面板**

- World 页「今日一签」：牌扣着，按「抽今天的签」翻开；七天横排可点开回看，回看的牌虚线边、带「回到今天」。
- 面板与服务端走同一条逻辑，只读——按钮不产生新的随机，也不替桌宠写正文。
- 浏览器产物 `dist/webui.js` 是手写原生 ES module（宿主按 URL import），无需打包步骤；`dist/webui.css` 只用宿主 CSS 变量，跟着主题走。

**发布状态**

- 带 `experimental` 标签：还没在真的 Coopanion 实例里加载过，只在干装载、假 DOM 与单元测试下验证过。
- 19 个文件、约 25 kB；无网络、无密钥、无第三方运行时依赖。
