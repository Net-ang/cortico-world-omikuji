# 精灵日签（cortico-world-omikuji）

每天一张签：分数、档位、签号，以及签文、解语、宜忌与幸运色。

**同一天在同一台机器上永远是同一张签；换一台机器就是另一套。**

措辞默认**由桌宠自己写**（`wording: "pet"`）：World 只给分数、档位与写作约束，句子是它说的。切成 `wording: "builtin"` 则用签库成句，完全不碰模型。

# 种子怎么来

```
每日盐 = 当天第一次「真抽签」时 crypto.randomBytes(8) 现摇，落盘（omikuji-days.json，只留七天）
种子   = SplitMix64( FNV-1a( "omikuji/v1|" + 该日盐 + "|" + YYYY-MM-DD ) )
分数   = 这条流上的第一次取数，范围 0–100
```

- **只有真抽签才摇盐。** 摇盐的入口有三个，且都指向"用户要签"这个动作：工具 `omikuji_draw`、面板的「抽今天的签」按钮（面板方法 `draw`）、以及桌宠按提示词取签。系统前缀那一行、打开面板、七天回看都只是**读**，走 `snapshot` / `envPromptVars`，不产生任何随机。
- **抽过就定了。** 当天摇出的盐落盘，这一天之内再抽、再读、重启，都是同一张。
- **没抽过的日子就是旧版那套。** 那一天没有人抽过签，事后回看它 = 日期 + 固定的本机盐（`omikuji-salt.json`），跟 0.1.3 算出来的完全一致——**不会因为事后去看就凭空摇一张出来**。
- **只留七天**：每次落盘裁掉七天前的条目；七天以外的日期同样走"日期 + 固定盐"那条路。
- 引擎是自己写的 SplitMix64（`src/rng.ts`），只有整数运算，不碰 `Math.random`、不碰语言的分布函数、不读时间。**唯一的熵源是 `crypto.randomBytes`**。

取数顺序也是约定的一部分：分数、签号、签文、解语、幸运色、宜、忌、意象依次从同一条流里取。改这个顺序会让所有日期的签全变，等同于换算法。

## 档位

0–100 被八档完整覆盖（`data/signs.json`，加载时校验不许有缝）：

| 分数 | 档位 | 分数 | 档位 |
|---|---|---|---|
| 90–100 | 上上签 | 35–44 | 平 |
| 76–89 | 大吉 | 22–34 | 末吉 |
| 60–75 | 中吉 | 10–21 | 小凶 |
| 45–59 | 小吉 | 0–9 | 大凶 |

内置模式每档 5 句签文、3 句解语，宜与忌各 24 条，幸运色 16 种。文案在 `data/signs.json`，改它不需要动代码——**档位与分数不变，变的只是挑中哪一句**。

## 措辞：内置 / 桌宠自己写

Cortico 的分层原则是 World 只给事实、话由 Persona 说。所以措辞归谁写是一个开关，不是硬编码：

```json
{ "worlds": { "omikuji": { "enabled": true, "wording": "pet" } } }
```

默认是 `pet`：这份扩展要的是「她自己的一签」，不是一批大家共用的句子。想省掉模型、要绝对稳定的文字，就切成 `builtin`。

| | `pet`（默认） | `builtin` |
|---|---|---|
| `omikuji_draw` 回什么 | 只有事实与约束：分数、档位、签号、该档分寸、三个可用意象 | 成句的签（签文、解语、宜、忌、色） |
| 谁写措辞 | 桌宠自己，写在自己的回复里 | 签库 |
| 恒定 | 当天首次写下的那份落盘，之后原样返回 | 代码保证，永远同一段文字 |
| 额外工具 | `omikuji_record` | 无 |
| 额外模型成本 | 无（它在回复里本来就要说话） | 无 |

`pet` 模式的闭环：

1. `omikuji_draw` → 拿到事实与写作约束（两句、14–18 字、不作断言、凶档不吓人）。
2. 桌宠照约束自己写一签。
3. `omikuji_record({ text })` → 落进 `<dataDir>/omikuji-wording-YYYY-MM.json`。
4. 同一天再 `omikuji_draw` → 原样返回存下那段，签文不再变。

**同一天只认第一份**：重复 record 不会覆盖，回执会说明保留的是先写下的那份。换一天、换月份各自独立。

代价写在明处：模型写古典对句普遍不如挑句子稳，`pet` 模式会出现平句和白话句——这是拿一致换个性。

## 面板：今日一签

World 页里有「今日一签」页签，**不开口也能自己抽**：

- 进来时牌是扣着的，按「抽今天的签」才翻开——翻开过的当天不再扣回去（记在面板自己的 `memo` 里）。
- 翻开的牌：第几签、档位、分数，加签文与解语（内置模式）或桌宠写下的那段（pet 模式已写）。
- **这七天**一条横排，点哪天看哪天；回看的牌用虚线边，带「回到今天」。
- 牌面只读。签由 (日期, 盐) 决定，按钮不产生新的随机，也不会替桌宠写正文。

pet 模式且当天还没写时，牌面显示「桌宠还没写这一签 —— 在对话里问一句」，并把这一档的分寸与可用意象列出来，方便你自己判断它会写成什么样。

面板与工具走同一条逻辑（`src/panel.ts` 调 `signFor`），所以界面上看到的分数、档位、签文与模型拿到的必然一致。

## 问一句就会答

环境提示词里写明了常见问法（「今日气运」「今天运势怎么样」「测测我今天」「今天顺不顺」这类）：**取一次签，用自己的话答**，除非对方要签本身，否则不贴回执原文；档位与分数必须照搬，语气归它自己。

这就是内置与 pet 两种模式的差别所在——内置模式它照着签文说，pet 模式它按分寸自己写。

## 工具

`omikuji_draw({ date? })`

- 不传参数：今天（按部署时区）。
- 传 `YYYY-MM-DD`：那一天。只认真实存在的日期，`2026-02-30` 直接报错。
- 同一天重复调用返回同一份内容，所以不必、也不该在同一天调用两次。

`omikuji_record({ text, date? })` —— 仅 `pet` 模式暴露。`text` 上限 200 字，空串与超长都拒绝。

内置模式的回执形如（分数只写数字加「分」，不写分母）：

```text
精灵日签 · 2026-11-23
第 7 签 · 小吉 · 48 分

签文：檐下滴水自成沟，日子长了自己有路。
解语：别把「还行」听成「不好」。
宜：跑一趟超市
忌：什么都推到明天
幸运色：藕荷
```

回执里不带免责声明——那句话摆在面板牌面上，每轮回执再重复一遍只会变成噪音。

`pet` 模式的回执形如：

```text
精灵日签 · 2026-11-23
第 7 签 · 小吉 · 48 分

这一签的措辞由你来写，分数和档位不能用别的话替换或改写。
这一档的分寸：只是小事，这本身就算好事。别拔高。
可用的意象（挑一两个，不用也不必全用）：檐、灯、路
写法：两句，一共 14–18 字；不作断言，不写「必然」「一定会」「注定」；读起来像随口说的话，不像通告。
语气的底线：这一签只当玩笑话，凶档也不许吓人、不许劝人改计划。免责那句话界面上一直摆着，别在每句回话后面再带一遍。
写完调用 omikuji_record，把你这一签的正文交上来——之后同一天再取，返回的就是你写下的那一份。
```

## 环境段与事件

- **环境段**每轮两行：今天的签号、档位与分数，以及措辞归谁写。
- **事件** `omikuji.started`：挂载时报今天的档位。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `worlds.omikuji.enabled` | `false` | 总开关 |
| `worlds.omikuji.wording` | `"pet"` | `pet` 或 `builtin`，下拉选择，热改。默认 `pet` |
| `worlds.omikuji.salt` | `""` | 固定的本机盐，**只用于七天以外的日期回落**。留空用自动生成的那一个 |

当天的签由当天现摇的随机盐决定，改 `salt` 不会动今天的签（除非今天还没要过签、盐还没生成）；改 `wording` 只改变措辞来源，分数与档位不动。

数据文件都在部署的数据目录里：

| 文件 | 内容 | 生命周期 |
|---|---|---|
| `omikuji-days.json` | 每天的随机盐 | 只留七天，每次落盘自动裁掉更早的 |
| `omikuji-salt.json` | 固定的本机盐（回落用） | 一直在，删了就换一个新的 |
| `omikuji-wording-YYYY-MM.json` | 桌宠自己写下的正文 | 按月存，不删 |

## 安装

在 Cortico WebUI 的扩展页安装 `cortico-world-omikuji`，或把本目录放进扩展目录。装后启用 `worlds.omikuji.enabled`。无网络、无密钥、无第三方运行时依赖。

## 开发

```sh
npm test            # 29 项：确定性与分布、日期校验、盐落盘、两种措辞模式、落盘与不覆盖、面板快照与方法
npm run typecheck
npm run check:client # 浏览器产物契约：bundle 形状、声明与实现的页签是否一一对上
npm run smoke:panel  # 假 DOM 里跑真客户端 + 真服务端：翻牌、七天、回看、pet 未写、报错重试
node tools/preview.ts 2026-11-23          # 内置模式的样子
node tools/preview.ts 2026-11-23 --pet    # pet 模式下模型拿到什么
npm run describe:self                     # 用框架导出器重写 describe.json 并干装载自检
node tools/copy-audit.ts                  # 签库统计：每档数量、时长分布、重复项
```

`npm run describe:self` 同时跑框架的 `checkDescribe` 与 `dryMountWorld`（manifest、配置组路径与默认值、工具前缀、事件、面板 id、环境段占位符）。改了工具声明、事件类型、配置组、面板或 `ENV_PROMPT.md` 之后必须重跑，`describe.json` 不能手改。

`dist/webui.js` 是**手写的原生 ES module，不是打包产物**（宿主按 URL import 它，浏览器直接跑）。所以本包没有 esbuild/pnpm 构建步骤，改完直接跑 `npm run check:client` 核对契约即可。样式在 `dist/webui.css`，只用宿主暴露的 CSS 变量，跟着主题走。

`--experimental-transform-types` 是给框架源码用的（它含参数属性），本包自己的源码不依赖它。

## 边界

- **签只是玩笑，不预测任何事。** 「相信科学，仅供娱乐参考。」这句只出现在面板牌面上（以及环境提示词里对凶档的约束），不进工具回执——回执每轮都进上下文，重复的免责句只会变成噪音。环境提示词另外写明凶档只是纸面话，不许吓人、不许劝人改计划。
- 回执里没有一句让 bot 把它当事实陈述的话，`ENV_PROMPT.md` 明确要求它用自己的口吻说。
- **过去七天之外的日子算不出当天那一张**：那天的随机盐已经按保留策略删掉了，回落到固定本机盐会得到另一张签。这是「只留七天」的代价——想留住某一天的签，抄下来，或者让桌宠把它写进措辞（措辞文件不删）。
- 删掉 `omikuji-salt.json` 或改 `worlds.omikuji.salt`，只影响回落那一路，不动今天的签。
- `pet` 模式下措辞由模型写，本 World 只保证「写下的就是之后返回的」；它保不了第一次写得好不好。
- 本 World 不写 Memory。今天的签由当日盐决定，`pet` 模式的措辞存在自己的文件里，不进 Memory。
